# Sujana Dinuwara | Software Engineering Portfolio

A modern, high-performance developer portfolio built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS v4**. 

🌐 **Live Demo**: [https://sujanadinuwara.vercel.app](https://sujanadinuwara.vercel.app)

---

## ⚡ Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **UI & Logic**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Form Integration**: [Formspree](https://formspree.io/)
- **Fonts**: [Geist](https://vercel.com/font)
- **Deployment**: [Vercel](https://vercel.com)

---

## ✨ Features

- 🌌 **Cyber-Space Theme**: Custom design system featuring dark mode aesthetics (`#0C0D0E`), neon glow accents (`#06B6D4`, `#A855F7`), and glassmorphism.
- 📱 **Fully Mobile Responsive**: Custom sliding navigation drawer, responsive grids, and touch-optimized controls.
- 🚀 **Projects Showcase**: Asymmetric card grid displaying real case studies (**ScanMark** dynamic QR attendance platform and **HireNear** location-aware freelance marketplace).
- 🎓 **Academic Milestone Timeline**: Visual timeline tracking Software Engineering degree progress at SLIIT and technical project executions.
- 📬 **Interactive Contact Form**: Secure message dispatch with Formspree integration and anti-spam honeypot protection.
- 🔍 **SEO & Security**: Full OpenGraph tags, automatic `sitemap.xml` & `robots.txt` generation, custom SVG brand favicon, and HTTP security headers (`X-Frame-Options`, `X-Content-Type-Options`).

## 🛠️ Local Development

### 1. Clone the repository
```bash
git clone https://github.com/IT24103033/Sujana-portfolio.git
cd Sujana-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_FORMSPREE_ID=your_formspree_id

```

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
